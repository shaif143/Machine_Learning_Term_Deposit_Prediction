# Term Deposit Prediction

Notebook-based binary classification study for predicting term-deposit
responses from the included `bank.csv` dataset. The notebook compares models,
uses grid search, evaluates a LightGBM model, and includes a user-input
prediction cell.

## Run

Use Python 3 with Jupyter and install `pandas`, `numpy`, `matplotlib`,
`seaborn`, `scikit-learn`, and `lightgbm`. When running locally, replace the
Google Colab path in the notebook with `bank.csv`.

This is an educational model and should not be used as financial advice.
